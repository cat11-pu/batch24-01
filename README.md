# GSB Bugfix Task
## 题面
下单接口信任前端传的数量和单价，负数、零、小数、布尔、超大数量和负单价都能算出合法总额，甚至缺价格也能过。order_total.py 的 total 需要重写，用例总数十五，现在一个都过不了。数量和单价必须是整数，数量限制在 1 到 999，单价非负且不超过上限，商品必须出现在价格表里，空订单、非字典、缺键、类型不符都抛 ValueError，正常订单返回正确总额。改完后我拿 1450 组随机订单压、24 路并发算总额；用例保持原样，上下限由参数传入。
