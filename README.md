# GSB Bugfix Task
## 题面
文件下载要解析 Range 头：只认 bytes 单位，单段和多段都要校验，段数有上限，起止必须有序且落在文件大小内，后缀范围和开放范围要处理，重叠、重复、空段和非法字符直接拒绝。parse_range 在 range_parser.py，十五个用例当前全部失败。header 必须是非空字符串，size 是非负整数，结果返回若干闭区间；类型错误、单位不符、越界和超量都报错。改完我拿 1300 组随机 Range 头、24 个线程并发解析；用例不许改，段数上限由参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
