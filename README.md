# GSB Bugfix Task
## 题面
压缩包解压现在直接把 entry 名字拼到目标目录，../、绝对路径、Windows 盘符、空字节、编码穿越和符号链接都能写到目标目录外。archive_guard.py 是核心，tests/test_archive_guard.py 15 个红。要修成 entry 规范化后必须落在目标目录内，绝对路径、盘符、..、空字节、编码穿越和符号链接都拒绝。修完 15 个测试后，还要保证 1000 组随机 entry 没有逃逸，32 线程并发校验不串目标目录；不许改测试或写死路径。边界至少覆盖 ../、嵌套 ..、绝对路径、盘符、空字节、编码穿越、符号链接。

## 运行方式
```bash
python -m pytest tests -q
```
