# GSB Bugfix Task
## 题面
密钥轮换要可回滚：服务必须存在，新密钥长度和字符集要合规，不能和最近三次重复，重叠期不能为负且不能超过上限，旧密钥在重叠期后失效，并发生成只能成功一次，活动密钥列表要能查到当前和过渡密钥。rotate 和 active_secrets 在 secret_rotation.py，十五条用例全部失败。store 是字典，service 和 secret 都要校验，now 是整数；未知服务、复用、越界和类型错误都报错。轮换演练：1300 组随机场景、25 个线程并行执行；用例不许动，重叠期上限由调用方定。

## 运行方式
```bash
python -m pytest tests -q
```
