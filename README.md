# GSB Bugfix Task
## 题面
事故证据下载票据的下载票据现在能猜、不绑响应人、不过期、能重复用，撤销和轮换也不生效。incident_ticket.py 是核心，tests/test_incident_ticket.py 15 个红。要修成随机且不可预测的下载票据、绑定事故、响应人和证据范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机票据、事故 ID、响应人和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码下载票据。边界至少覆盖空事故、空响应人、ttl 为 0、跨事故下载、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
