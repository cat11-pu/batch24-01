# GSB Bugfix Task
## 题面
权限中间件要在返回前裁字段：字段策略按角色声明读权限和写权限，嵌套结构递归处理，密码散列一类的字段对任何角色都不可见，写请求只能改自己有权改的字段，通配角色也不能绕过敏感字段。mask_fields.py 的 project 要实现这套裁剪，套件里十五条测试当前全挂。记录和策略必须是字典，角色不能为空，方向只认 read 和 write，策略缺项或类型不对都算失败；返回新对象，不改原记录。验收准备 1200 组随机记录和角色、24 个线程同时裁剪；测试保持原样，角色表交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
