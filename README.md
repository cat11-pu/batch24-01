# GSB Bugfix Task
## 题面
注册入口收到邮箱后先做标准化：空白先剥掉，域名小写并转 punycode，local part 保留大小写但首尾不能有点、中间不能连续点，标签和总长度都要卡住，显示名、控制字符、多个 @、IP 字面量和非法标签一律拒收。email_canonical.py 的 canonicalize_email 负责转换，现有十五条测试全部报错。入参得是非空字符串，返回值要能直接入库；有歧义的写法不能放过。上线前用 1400 个随机地址、20 个线程压转换；测试文件不许动，长度上限由调用方决定。

## 运行方式
```bash
python -m pytest tests -q
```
