# GSB Bugfix Task
## 题面
员工目录的搜索框把输入拼进 XPath，单引号和方括号能改写查询结构，甚至用 | 联合出别的节点。xpath_guard.py 里的 build_xpath 负责拼查询，用例总共十五个，眼下无一通过。用户名只允许字母、数字、下划线和连字符；引号、方括号、竖线、圆括号、斜杠、空白、NUL、换行、数字类型和 None 都要拒绝并抛 ValueError，字符集由调用方传入。改完后我生成 1000 组随机用户名、16 路并发压查询构造；用例保持原样，字符集也别写死。

## 运行方式
```bash
python -m pytest tests -q
```
