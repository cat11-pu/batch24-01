# GSB Bugfix Task
## 题面
退款申请先算可退余额，再走审批：已支付订单才能提交，金额不能超过剩余额度；发起人不能批自己的单，五百以上要两名不同审批人，批准后才允许落账，落账一次后余额不能再退。refund_workflow.py 的 apply 负责判断这一步能不能落账，十五条用例眼下全部失败。入参、金额和操作人都要校验，字段缺失或值非法直接报错；同时落账只能成功一笔。上线前用 1400 条随机退款流程、28 个线程并发推进；断言文件保持原样，审批阈值交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
