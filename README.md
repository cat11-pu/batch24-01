# GSB Bugfix Task
## 题面
依赖锁文件要逐项核验：包名必须在允许列表，版本必须精确锁定，哈希必须匹配策略里的值，低于最低版本、被禁包、哈希缺失或格式不对都拒绝，名字近似允许包但不在列表里的也要拦，策略为空和类型错误直接报错。dependency_guard.py 的 verify 负责核验，十五条用例眼下全挂。lockfile 和 policy 用字典，版本和哈希都要校验；坏输入和并发校验结果必须一致。校验演练：1320 个随机包、22 个线程一起跑；测试文件不许动，最低版本由使用方定。

## 运行方式
```bash
python -m pytest tests -q
```
