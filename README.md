# GSB Bugfix Task
## 题面
文件分享链接现在这套分享令牌能猜、不绑文件、不过期、能重复用，撤销和轮换也不生效。share_link.py 是核心，tests/test_share_link.py 15 个红。要修成随机且不可预测的分享令牌、绑定文件归属和访问范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、文件 ID、scope 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码分享令牌。边界至少覆盖空文件、空令牌、ttl 为 0、越权访问、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
