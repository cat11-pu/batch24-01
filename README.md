# GSB Bugfix Task
## 题面
风控评分按规则累加：金额、速度、地理跳变、新设备和历史拒付分别计分，命中就加，总分封顶一百；低于阈值放行，中间转人工，高分直接拦。fraud_rules.py 的 score 负责计算，十五条用例眼下全挂。事件和画像用字典，规则用列表，时间取整数；规则类型不认识、权重缺失、输入类型不对都算失败，同一事件并发评分必须同结果。上线压测：1420 组随机事件、27 个线程跑评分；用例文件不许动，阈值由使用方设定。

## 运行方式
```bash
python -m pytest tests -q
```
