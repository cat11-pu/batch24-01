# GSB Bugfix Task
## 题面
履约环节要防止越级操作：拣货前必须已付款，出库前必须完成拣货，签收前必须出库，已出库的订单不能直接取消，退款只能发生在已付款且未签收的订单上，付款金额还必须和订单金额一致。order_workflow.py 的 apply 负责判定当前动作是否允许，套件十五条测试眼下全挂。订单记录得带当前环节、金额、是否付款，动作和操作人不能为空；动作未知、环节未知或类型不对一律算失败。验收时准备 1450 组随机履约序列、27 个线程并行推进；测试文件原样保留，环节名由调用方定。

## 运行方式
```bash
python -m pytest tests -q
```
