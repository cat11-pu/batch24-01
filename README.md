# GSB Bugfix Task
## 题面
留存策略要看数据本身：订单类到期就清，资料类到期先匿名化，处于法律保留状态的一律不动；记录缺少类别、创建时间、租户或保留标记就拒收，时间倒流和跨租户也拒收，策略动作只认 keep、purge、anonymize。data_retention.py 里的判定函数负责给出结论，十五条用例眼下全挂。入参和规则表用字典，当前时间取整数；返回 keep、purge 或 anonymize。上线前用 1270 条随机记录、22 个线程压判定；测试保持原样，留存天数由使用方给。

## 运行方式
```bash
python -m pytest tests -q
```
