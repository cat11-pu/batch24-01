# GSB Bugfix Task
## 题面
账单发票下载令牌的发票令牌现在能猜、不绑客户、不过期、能重复用，撤销和轮换也不生效。invoice_token.py 是核心，tests/test_invoice_token.py 15 个红。要修成随机且不可预测的发票令牌、绑定客户、账单周期和下载范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、客户 ID、账单周期和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码发票令牌。边界至少覆盖空客户、空账单、ttl 为 0、跨客户下载、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
