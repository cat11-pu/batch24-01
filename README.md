# GSB Bugfix Task
## 题面
邮件发送接口把收件人、抄送、密送和主题直接拼进邮件头，换行能注入额外收件人和头字段。email_guard.py 是核心，tests/test_email_guard.py 15 个红。要修成所有头字段拒绝 CR、LF、NUL 和控制字符，收件人必须是合法地址，空收件人和空主题拒绝，显示名不能带换行。修完 15 个测试后，还要保证 1000 组随机收件人和主题没有头注入，32 线程并发校验不串状态；不许改测试或硬编码输入。边界至少覆盖 LF、CRLF、NUL、空收件人、空主题、非法地址、显示名换行。

## 运行方式
```bash
python -m pytest tests -q
```
