# GSB Bugfix Task
## 题面
Webhook 密钥轮换令牌的轮换令牌现在能猜、不绑回调端点、不过期、能重复用，撤销和轮换也不生效。webhook_secret.py 是核心，tests/test_webhook_secret.py 15 个红。要修成随机且不可预测的轮换令牌、绑定端点、租户和密钥版本、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、端点 ID、密钥版本和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码轮换令牌。边界至少覆盖空端点、空租户、ttl 为 0、旧版本重放、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
