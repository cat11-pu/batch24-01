# GSB Bugfix Task
## 题面
审计日志要做哈希链：每条记录带递增序号、前一条哈希和本条 HMAC，事件用规范化 JSON 参与计算，任何一条被改、被删、被换序或换密钥都要验不出来。append 和 verify 在 audit_chain.py，十五个用例现在全部不通过。事件必须是字典且不能为空，链必须是列表，密钥不能为空；verify 空链返回 False，结构缺字段返回 False，并发追加的序号不能重复。改完我用 31 个线程同时追加和校验；测试不能改，哈希算法由参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
