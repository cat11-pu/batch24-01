# GSB Bugfix Task
## 题面
游戏资源下载票据现在这套票据能猜、不绑玩家、不过期、能重复用，撤销和轮换也不生效。download_ticket.py 是核心，tests/test_download_ticket.py 15 个红。要修成随机且不可预测的票据、绑定文件归属和下载次数、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机票据、文件 ID 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码票据。边界至少覆盖空玩家、空文件、ttl 为 0、重复下载、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
