# GSB Bugfix Task
## 题面
会话只认 cookie 里的 ID，不绑定设备，令牌被复制到另一台机器照样能用。session_bind.py 的 check_binding 要补上设备校验，现成那十五个断言眼下全红。绑定信息和当前信息都只能是字典，ua、ip 前缀、TLS 指纹三个字段缺一不可且不能为空；任意一项对不上就拒绝，首尾空白、非字符串和空字典同样不行，三项全一致才通过。交付前造 1100 组随机设备信息、22 个线程一起比对；测试保持原样，字段集合交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
