# GSB Bugfix Task
## 题面
秒杀接口先读库存再写回，两个请求同时进来会把同一件商品卖两次，库存还能被扣成负数。reserve 在 stock_reserve.py，仓库里十五个用例目前没有一条通过。库存和购买量必须是非负整数，购买量至少为 1 且不能超过库存，单次上限也要卡住，布尔、浮点、字符串和 None 都拒绝，预留表不是字典要报错，扣减要在锁内完成。改完我用 1400 组随机库存和并发请求、32 个线程同时抢；测试文件不能改，单次上限从参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
