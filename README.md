# GSB Bugfix Task
## 题面
客服工单里有人反馈：登录页对不存在的账号提示“用户不存在”，对锁定账号提示“账号已锁定”，密码错误又是另一句，响应时间也随账号是否存在而变化——这等于把账号枚举接口直接暴露给攻击者。respond 在 login_response.py，仓库自带的 15 条断言现在全部失败。要求所有失败路径返回同一句话、同一个状态码，锁定和不存在都不能泄露，只有成功才回 ok，非布尔入参要报错。这 15 条通过后，我会用 2000 组随机入参、48 路并发比对响应是否完全一致；用例和文案都不许改或写死。不存在、密码错、锁定、非布尔、空值、并发都要覆盖。

## 运行方式
```bash
python -m pytest tests -q
```
