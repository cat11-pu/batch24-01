# GSB Bugfix Task
## 题面
内容协商只看第一个支持类型，Accept 里写 */*、text/* 或 q=0 也能拿到 JSON，缓存层和业务层对同一请求给出不同表示。accept_guard.py 的 negotiate 负责选型，当前十五条测试全部报错。Accept 必须是非空字符串，只认明确列出的具体类型；通配符、q=0、非法 q 值、重复 q、空元素、尾逗号、大小写变体、换行和 NUL 一律报错，多个合法类型按出现顺序取第一个。上线前跑 1150 组随机 Accept 头、19 个线程做并发协商；断言文件保持原样，支持类型由调用方给出。

## 运行方式

```bash
python -m pytest tests -q
```
