# GSB Bugfix Task
## 题面
家长同意令牌的同意令牌现在能猜、不绑监护人、不过期、能重复用，撤销和轮换也不生效。consent_token.py 是核心，tests/test_consent_token.py 15 个红。要修成随机且不可预测的同意令牌、绑定监护人、儿童和被同意范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、监护人 ID、儿童 ID 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码同意令牌。边界至少覆盖空监护人、空儿童、ttl 为 0、跨儿童同意、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
