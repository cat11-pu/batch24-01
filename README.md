# GSB Bugfix Task
## 题面
活动页的回跳参数没做约束，用户登录完可能被带去双斜杠地址、反斜杠变体，或者伪装成子域名的钓鱼站。redirect_guard.py 里的 safe_redirect 负责把关，仓库附带的十五条断言现在全部报错。只放行加密协议，主机名要和调用方给的白名单逐字符一致，非标准端口、带认证信息的地址、末尾点、路径里的上级引用、CR/LF、NUL 和空串都拒绝，合法路径原样返回。这十五条绿了以后，我会再生成 1700 组随机跳转目标、26 路并发调用；用例不能动，白名单从参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
