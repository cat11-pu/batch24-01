# GSB Bugfix Task
## 题面
CI 制品下载令牌的下载令牌现在能猜、不绑构建任务、不过期、能重复用，撤销和轮换也不生效。ci_artifact.py 是核心，tests/test_ci_artifact.py 15 个红。要修成随机且不可预测的下载令牌、绑定构建任务和制品范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、构建 ID、制品 ID 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码下载令牌。边界至少覆盖空构建、空制品、ttl 为 0、跨制品下载、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
