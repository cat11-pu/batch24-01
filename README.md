# GSB Bugfix Task
## 题面
登录失败响应区分账号不存在、密码错误和账号锁定，攻击者能批量枚举账号，还能从响应时间判断账号是否存在。login_response.py 的 respond 是核心，tests/test_login_response.py 15 个红。要修成所有失败统一返回同一文案和同一状态码，锁定和不存在不暴露，成功才返回 ok，非布尔输入拒绝。15 个红测之后，再用 1000 组随机组合和 32 线程并发校验，确认响应不可区分；不许改测试或硬编码文案。边界至少覆盖不存在、密码错误、锁定、非布尔、空值和并发。

## 运行方式
```bash
python -m pytest tests -q
```
