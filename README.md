# GSB Bugfix Task
## 题面
共享缓存要按规范化结果生成键：主机必须在允许清单、路径先折叠点段、查询参数排序且不允许重复键、Vary 声明的头进入键、认证和 Cookie 不参与公共缓存、非标准端口和片段直接拒绝。cache_vary.py 的 cache_key 负责生成，现有十五条测试全部挂掉。入参和策略都必须是字典，方法只认 GET/HEAD，host、path、query、headers 都要校验；不合规组合直接拒绝，通过校验时返回稳定字符串。交付前拿 1450 个随机请求、27 个线程一起生成；用例不许动，允许主机和 Vary 由调用方给出。

## 运行方式
```bash
python -m pytest tests -q
```
