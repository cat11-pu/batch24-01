# GSB Bugfix Task
## 题面
审批链按金额分档：小额一级经理可批，大额必须总监，超过上限直接拒绝，发起人不能自批，同一审批人不能重复计数，记录不足返回 pending，明确拒绝返回 rejected，角色未知和类型错误都报错。approval_chain.py 里的 decide 要把关，十五条用例眼下全挂。request、policy 用字典，金额取非负整数，审批列表结构不能缺，角色映射由参数给出。压测计划：1350 份审批单、23 个线程并行跑；测试文件别改，阈值交给使用方。

## 运行方式
```bash
python -m pytest tests -q
```
