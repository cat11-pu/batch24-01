# GSB Bugfix Task
## 题面
事件响应像接力：发现后先定级，分级时必须落到具体负责人；遏制完成才允许清除，恢复完成才允许关单，关单只能由响应负责人操作；P1 拖过一小时自动升级，跳步、重复关单和不认识的状态都拒绝。incident_workflow.py 的 transition 推动这条时间线，十五条用例眼下全挂。记录字段不齐或状态不认识直接报错，操作人和时间也要校验；非法流转一律拒绝。上线前用 1320 组随机事件、22 个线程压推进；测试文件别改，SLA 时长由使用方定。

## 运行方式
```bash
python -m pytest tests -q
```
