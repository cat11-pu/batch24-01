# GSB Bugfix Task
## 题面
网关把请求头全量读进内存，头数量、单头长度和总字节数都不设上限，攻击者用几万个头或一个超长 Cookie 就能把 worker 拖死。header_size_guard.py 的 check_headers 要加三道闸，现有测试套件十五条全挂。headers 得是 (name, value) 二元组列表，名字不能为空、不能含控制字符；数量、单头长度、总字节数任一越界，元素结构不对或类型不符，都算失败，正常请求头才通过。上线前我准备 1150 组随机头集合、19 个线程并发检查；原有断言不许改，三个上限由调用方给出。

## 运行方式
```bash
python -m pytest tests -q
```
