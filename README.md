# GSB Bugfix Task
## 题面
CSRF 校验现在直接放行：令牌可预测、不绑会话、不过期、能重复用、旋转不失效，任何请求方法都接受。csrf_guard.py 是核心，tests/test_csrf_guard.py 15 个红。要修成令牌随机且绑会话、按 TTL 过期、一次校验后作废、旋转后旧令牌失效、只接受安全的请求方法组合。修完 15 个测试后，还要保证 1000 组随机会话和令牌没有绕过，32 线程并发校验同一令牌只能成功一次；不许改测试或硬编码令牌。边界至少覆盖空令牌、空会话、过期、重放、跨会话、非法方法。

## 运行方式
```bash
python -m pytest tests -q
```
