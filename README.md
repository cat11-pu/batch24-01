# GSB Bugfix Task
## 题面
邀请返利上线后出现自己邀请自己、A 邀 B 再让 B 邀 A 的循环，以及一次性邮箱批量注册，返利池被迅速掏空。validate_referral 在 referral_guard.py，用例一共十五个，目前没有一条能过。要求邀请人和被邀请人不能相同（忽略大小写和空白），两边都必须是合法邮箱，域名不能落在一次性邮箱名单里，被邀请人不能已经被别人邀请过，也不能形成推荐链环，推荐层级超过五层同样拒绝，历史结构不是字典要报错。改完后我用 1400 组随机邀请关系、20 个线程同时校验；用例保持原样，一次性域名名单从参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
