# GSB Bugfix Task
## 题面
订阅计费要按周期出账：只有 active 状态能计费，周期没结束不能提前出，同一周期只能出一张账单，价格和币种必须合法，周期边界要合理，并发出账只能成功一次，取消和欠费状态直接拒绝。subscription_billing.py 的 bill 负责出账，十五条用例眼下全挂。subscription 用字典，时间戳为整数，金额取正整数，价格不能为零；字段缺失、类型不符和重复出账都算失败。压测安排：1480 份订阅和周期、29 个线程并行出账；测试文件别改，周期长度交给使用方。

## 运行方式
```bash
python -m pytest tests -q
```
