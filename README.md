# GSB Bugfix Task
## 题面
反作弊证据上传令牌的上传令牌现在能猜、不绑审核员、不过期、能重复用，撤销和轮换也不生效。anticheat_upload.py 是核心，tests/test_anticheat_upload.py 15 个红。要修成随机且不可预测的上传令牌、绑定案件、上传人和证据范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、案件 ID、审核员和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码上传令牌。边界至少覆盖空案件、空审核员、ttl 为 0、跨案件上传、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
