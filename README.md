# GSB Bugfix Task
## 题面
图片上传只检查文件大小，不检查像素总量，一张几十 KB 的压缩图解压后能占几 GB 内存。validate_image 在 image_bomb_guard.py，仓库里的 15 条 param 用例现在全部失败。要求宽高和文件大小都是非负整数，单边和总像素都不能超过调用方给的上限，零尺寸、负数、浮点、字符串、布尔和 None 都要拒绝，正常图片返回 True。这 15 条通过后，我用 1000 张随机尺寸的图、16 个线程同时校验；测试文件保持原样，阈值必须从调用方传入。

## 运行方式
```bash
python -m pytest tests -q
```
