# GSB Bugfix Task
## 题面
规则引擎只允许四则运算和括号：表达式里的变量、函数调用、属性访问、下划线、引号、分号、条件表达式、列表和 lambda 全部拒绝，深度和长度有上限，除零和超大指数也要拦住。expression_eval.py 的 evaluate 负责求值，眼下十五条断言没有一条能过。expr 得是字符串且不能为空，输出数值；非法语法、超限和危险构造都算失败。交付时拿 1450 个随机表达式批量求值，线程数拉到 26；断言文件保持原样，两个阈值交给调用方定。

## 运行方式
```bash
python -m pytest tests -q
```
