# GSB Bugfix Task
## 题面
XML 用户查询把用户名直接拼进 XPath 表达式，单引号、方括号和 or 1=1 能改掉整个查询条件。xpath_guard.py 是核心，tests/test_xpath_guard.py 15 个红。要修成用户名只作为字面量、拒绝引号、方括号、斜杠、星号、函数调用和控制字符，非法值明确报错。修完 15 个测试后，还要保证 1000 组随机输入没有 XPath 注入，32 线程并发校验不串状态；不许改测试或硬编码用户名。边界至少覆盖单引号、双引号、方括号、双斜杠、星号、函数调用、NUL 和空值。

## 运行方式
```bash
python -m pytest tests -q
```
