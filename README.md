# GSB Bugfix Task
## 题面
动态口令校验要支持计数器窗口：按 HOTP 算码，允许向后看几个计数器，命中后返回下一次该用的计数器，已经用过的计数器不能重放，窗口、位数、密钥和计数器都要校验。hotp_window.py 的 verify 负责计算，套件十五条测试眼下全部失败。code 得是六位数字串，secret 不能为空，counter 为非负整数，used 用集合；异常输入、窗口非法和重放都算失败。验收时准备 1150 个随机验证码、21 个线程一起校验；断言文件保持原样，窗口和位数由调用方定。

## 运行方式
```bash
python -m pytest tests -q
```
