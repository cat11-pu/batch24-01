# GSB Bugfix Task
## 题面
会话令牌这块现在有问题：令牌能猜到、不绑用户、不过期、能重复用，退出登录也清不掉。session_guard.py 是核心，tests/test_session_guard.py 15 个红。要修成令牌随机且不可预测、绑定用户、按 TTL 过期并清理、一次校验后立即作废、退出登录和改密后旧令牌全部失效。修完 15 个测试后，还要保证 1000 组随机用户和令牌输入下没有绕过，32 线程并发校验同一令牌只能成功一次；不许改测试或用固定标记表绕过。边界至少覆盖空用户、空令牌、ttl 为 0、过期边界、注销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
