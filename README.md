# GSB Bugfix Task
## 题面
智能设备配对码现在这套配对码能猜、不绑设备、不过期、能重复用，撤销和轮换也不生效。device_pairing.py 是核心，tests/test_device_pairing.py 15 个红。要修成随机且不可预测的配对码、绑定设备指纹和配对窗口、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机配对码、设备 ID 和时间戳和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码配对码。边界至少覆盖空设备、空配对码、ttl 为 0、重复配对、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
