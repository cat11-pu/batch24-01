# GSB Bugfix Task
## 题面
分块传输接口按 chunk 累加长度，既不限单块大小也不限总长度和块数量，攻击者发几十万个块就能把解析器拖住。chunked_limit.py 的 check_chunked 要设三道闸，套件里十五条用例现在全挂。块大小只能是整数且不能小于零；单块超额、累计超额、块数过多、空序列，或元素混进小数、文本、真假值和空值，全部报错。交付前拿 1100 组随机块序列、18 个线程压一遍；用例保持原样，三个阈值交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
