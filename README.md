# GSB Bugfix Task
## 题面
KYC 证件访问票据的访问票据现在能猜、不绑审核员、不过期、能重复用，撤销和轮换也不生效。kyc_ticket.py 是核心，tests/test_kyc_ticket.py 15 个红。要修成随机且不可预测的访问票据、绑定申请人、证件类型和访问范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机票据、申请 ID、审核员和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码访问票据。边界至少覆盖空审核员、空申请、ttl 为 0、跨申请访问、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
