# GSB Bugfix Task
## 题面
改密页面只检查长度，用户能把密码改回原来那个，也能设成 password1234 这类字典口令。check_password 在 password_history.py，仓库给的十五条断言现在没有一条能过。新密码不能和最近五次历史重复（忽略大小写），长度至少十二位，不能是常见弱口令，不能包含用户名，首尾空白和纯空白都拒绝，历史不是列表或元素不是字符串要报错，用户名也不能为空。交付前我准备 1300 组随机密码和历史、20 个线程同时校验；测试不许动，复用次数和最小长度由参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
