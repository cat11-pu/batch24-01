# GSB Bugfix Task
## 题面
退款审批令牌的审批令牌现在能猜、不绑财务、不过期、能重复用，撤销和轮换也不生效。refund_approval.py 是核心，tests/test_refund_approval.py 15 个红。要修成随机且不可预测的审批令牌、绑定订单、退款金额和审批人、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、订单 ID、金额和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码审批令牌。边界至少覆盖空订单、空金额、ttl 为 0、超额审批、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
