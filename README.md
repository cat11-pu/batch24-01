# GSB Bugfix Task
## 题面
日志字段直接拼接用户输入，换行能伪造日志行，CR、制表符、NUL 和终端转义序列也能原样写进日志。log_guard.py 是核心，tests/test_log_guard.py 15 个红。要修成控制字符全部转义、空输入和非字符串拒绝，合法文本保持不变。修完 15 个测试后，还要保证 1000 组随机输入没有日志伪造，32 线程并发转义不串状态；不许改测试或硬编码输入。边界至少覆盖 LF、CRLF、制表符、NUL、ANSI 转义、垂直制表、换页、退格和响铃。

## 运行方式
```bash
python -m pytest tests -q
```
