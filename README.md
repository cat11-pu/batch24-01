# GSB Bugfix Task
## 题面
代码仓库要定期扫泄露：文件集合和规则表都要校验，规则带 id、匹配串和严重级别，命中要记录路径和规则，高危命中直接拦截，重复规则 id、空匹配串、非法级别和类型错误都要报错；路径白名单由调用方给出。secret_exposure.py 的 scan 负责扫描，十五条用例眼下全挂。files 是路径到内容的字典，rules 是列表；异常输入和并发扫描结果必须一致。扫描安排：1450 个随机文件、26 个线程并行扫；用例文件别改，拦截级别由使用方给。

## 运行方式
```bash
python -m pytest tests -q
```
