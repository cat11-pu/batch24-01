# GSB Bugfix Task
## 题面
电子签名信封令牌的签名令牌现在能猜、不绑签署人、不过期、能重复用，撤销和轮换也不生效。esign_token.py 是核心，tests/test_esign_token.py 15 个红。要修成随机且不可预测的签名令牌、绑定信封、签署人和签署顺序、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、信封 ID、签署人和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码签名令牌。边界至少覆盖空签署人、空信封、ttl 为 0、重复签署、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
