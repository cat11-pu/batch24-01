# GSB Bugfix Task
## 题面
库存预占要支持过期释放和并发抢购：同一 SKU 的可用量等于库存减去未过期的预留，超卖必须拒绝，过期预留要在下一次操作时自动清掉，预留 ID 不能重复。reserve 在 inventory_lock.py，十五个用例当前全部失败。stock 和 reservations 都必须是字典，sku 不能为空，数量是 1 到 999 的整数，ttl 正数，时间戳整数；类型不对、库存不足、重复预留都算失败，并发下只能有一个请求抢到剩余库存。验收拿 31 个线程同时抢同一批库存；断言保持原样，ttl 和单次上限交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
