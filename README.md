# GSB Bugfix Task
## 题面
临时文件创建要原子且不能跟随链接：文件名先 basename 化，上级引用、绝对路径、NUL 和过长名字都拒绝，目标已存在直接失败，父目录里的符号链接不能把写入带出根目录，权限只允许属主读写一类安全值。create_file 在 file_create.py，十五个用例当前全部失败。data 必须是 bytes，base 必须是目录，mode 必须是整数且在白名单里；成功返回落盘路径。验收准备 1100 个随机路径、22 个线程一起创建；断言文件保持原样，根目录和权限白名单交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
