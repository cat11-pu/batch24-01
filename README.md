# GSB Bugfix Task
## 题面
上传落盘后权限位直接照搬临时文件，世界可写、可执行甚至 setuid 都可能留下，其他用户能改内容再让服务执行。check_mode 在 file_permission.py，仓库里的十五条断言目前全红。权限位必须是整数，世界可写、任意执行位、setuid、setgid、sticky 和超出常规范围的位都拒绝，负数、浮点、字符串、布尔和 None 同样报错，只有属主可读写这类安全组合才通过。验收时准备 800 组随机权限位、14 个线程同时检查；测试保持原样，允许的位掩码通过参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
