# GSB Bugfix Task
## 题面
LDAP 用户搜索把用户名直接拼进过滤器，*)(uid=* 这类输入能改变查询结构。ldap_guard.py 是核心，tests/test_ldap_guard.py 15 个红。要修成按 RFC 4515 转义、拒绝 NUL、空用户和非字符串，且合法用户名保持不变。修完 15 个测试后，还要保证 1000 组随机输入没有注入，32 线程并发校验不串状态；不许改测试或硬编码输入。边界至少覆盖 *、()、反斜杠、NUL、空值、非字符串、换行。

## 运行方式
```bash
python -m pytest tests -q
```
