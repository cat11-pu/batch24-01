# GSB Bugfix Task
## 题面
比赛回放访问票据的回放票据现在能猜、不绑赛事运营、不过期、能重复用，撤销和轮换也不生效。replay_ticket.py 是核心，tests/test_replay_ticket.py 15 个红。要修成随机且不可预测的回放票据、绑定赛事、比赛和访问范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机票据、赛事 ID、比赛 ID 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码回放票据。边界至少覆盖空赛事、空比赛、ttl 为 0、跨赛事访问、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
