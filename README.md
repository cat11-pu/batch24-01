# GSB Bugfix Task
## 题面
数据导出任务令牌现在这套导出令牌能猜、不绑任务、不过期、能重复用，撤销和轮换也不生效。export_token.py 是核心，tests/test_export_token.py 15 个红。要修成随机且不可预测的导出令牌、绑定任务归属和一次性下载、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、任务 ID 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码导出令牌。边界至少覆盖空任务、空令牌、ttl 为 0、重复下载、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
