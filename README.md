# GSB Bugfix Task
## 题面
优惠券要支持组合使用但必须有边界：最多两张、同类型不能叠加、互斥券只能单独用、每张券有门槛、适用商品或品类、有效期和每人次数限制，抵扣不能超过订单总额。redeem 在 coupon_stack.py，现有十五个用例全部挂掉。coupons 是列表，cart 带总额和条目，user 带已用次数；空列表、超量、重复类型、过期、门槛不足、范围不符、次数超限、互斥冲突都要抛 ValueError，合法组合返回总抵扣。改完我拿 1300 组随机券和购物车、26 个线程并发核销；用例不许改，规则参数不能写死。

## 运行方式
```bash
python -m pytest tests -q
```
