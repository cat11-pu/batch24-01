# GSB Bugfix Task
## 题面
支付确认令牌现在这套支付令牌能猜、不绑订单、不过期、能重复用，撤销和轮换也不生效。payment_confirm.py 是核心，tests/test_payment_confirm.py 15 个红。要修成随机且不可预测的支付令牌、绑定订单归属和金额范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、订单 ID、金额和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码支付令牌。边界至少覆盖空订单、空令牌、ttl 为 0、金额不符、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
