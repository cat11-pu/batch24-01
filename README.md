# GSB Bugfix Task
## 题面
临时访客通行证现在这套通行证能猜、不绑访客、不过期、能重复用，撤销和轮换也不生效。guest_pass.py 是核心，tests/test_guest_pass.py 15 个红。要修成随机且不可预测的通行证、绑定访客归属和区域范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机通行证、访客 ID、区域和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码通行证。边界至少覆盖空访客、空通行证、ttl 为 0、越区访问、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
