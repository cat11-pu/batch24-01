# GSB Bugfix Task
## 题面
多语言站点要按客户端偏好选语言：逗号分隔的标签逐个解析，q 值必须落在 0 到 1，重复标签、重复 q、空元素、非法 q 和全零权重都拒绝，通配和前缀回退要处理，排序先看权重再看先后。negotiate 在 accept_language.py，仓库十五个用例全部失败。header 必须是非空字符串，supported 是非空列表；合法请求返回命中的语言标签。验收拿 1500 个随机偏好串、26 个线程一起协商；断言不许改，支持语言交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
