# GSB Bugfix Task
## 题面
内容申诉处理令牌的申诉令牌现在能猜、不绑申诉人、不过期、能重复用，撤销和轮换也不生效。appeal_token.py 是核心，tests/test_appeal_token.py 15 个红。要修成随机且不可预测的申诉令牌、绑定申诉单、申诉人和处理范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、申诉单 ID、申诉人和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码申诉令牌。边界至少覆盖空申诉单、空申诉人、ttl 为 0、跨申诉单处理、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
