# GSB Bugfix Task
## 题面
上传接口支持 gzip 压缩体，解压后的大小和压缩比都没人算，几十 KB 的包能膨胀到几十 GB 把内存打穿。gzip_bomb.py 里的 validate_gzip 要负责拦截，随包给的十五个断言目前全部报错。压缩前和解压后的字节数都得是整数且不能为负，压缩比为 0 或解压结果为空同样算异常，膨胀倍数超过一百、解压总量越过上限、参数混进浮点、字符串、布尔或 None 时一律 ValueError，合规的包才放行。交付前我会造 1200 个随机包、18 个线程一起跑校验；断言别改，两个阈值交给调用方。

## 运行方式
```bash
python -m pytest tests -q
```
