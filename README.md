# GSB Bugfix Task
## 题面
结算引擎要算清金额：条目数量、单价、折扣比例、折扣上限、税率、最小起算金额和舍入都要参与，最终结果以分为单位且必须可复现。quote 在 pricing_engine.py，十五个用例现在全挂。items 必须是列表，sku 不能重复，数量是 1 到 999 的整数，单价是非负整数，税率和折扣率用万分比表示，币种是三位大写字母；任何类型不符或越界都报错，合法订单返回 subtotal、discount、tax、total。改完我用 1500 组随机订单、28 个线程并发算价；测试不能改，规则从参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
