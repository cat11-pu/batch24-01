# GSB Bugfix Task
## 题面
对账要能定位差异：本地和渠道各有一张交易表，金额必须是非负整数，交易号非空，缺本地、缺渠道、金额不一致都要分别列出来，匹配数量要算对，表结构不对或金额类型不对直接报错，两个线程同时对账结果必须一致。reconcile 在 payment_reconciliation.py，十五条用例当前全红。local 和 remote 都是字典，now 取整数；异常输入和重复交易号都要挡住。对账演练：1380 组随机交易、26 个线程并行跑；断言文件保持原样，差异分类由使用方定。

## 运行方式
```bash
python -m pytest tests -q
```
