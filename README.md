# GSB Bugfix Task
## 题面
客服代操作授权现在这套授权令牌能猜、不绑客服、不过期、能重复用，撤销和轮换也不生效。support_grant.py 是核心，tests/test_support_grant.py 15 个红。要修成随机且不可预测的授权令牌、绑定目标用户和操作范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、用户 ID、scope 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码授权令牌。边界至少覆盖空客服、空用户、ttl 为 0、越权 scope、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
