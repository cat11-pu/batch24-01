# GSB Bugfix Task
## 题面
转账账本要保证原子和幂等：账户必须存在且不能相同，金额是正整数，余额不足拒绝，扣款和入账要一起成功，同一个幂等键重复提交返回原结果，换内容同键直接冲突，并发下不能透支。ledger_transfer.py 的 transfer 负责记账，十五条用例眼下全挂。ledger 和 idem 用字典，key 非空，账户名和金额类型都要校验；失败不能留下半笔账。压测安排：1520 组随机转账、31 个线程并行压；测试文件别改，账户表交给使用方。

## 运行方式
```bash
python -m pytest tests -q
```
