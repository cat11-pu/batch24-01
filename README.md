# GSB Bugfix Task
## 题面
IoT 设备命令令牌的命令令牌现在能猜、不绑设备、不过期、能重复用，撤销和轮换也不生效。iot_command.py 是核心，tests/test_iot_command.py 15 个红。要修成随机且不可预测的命令令牌、绑定设备、命令类型和序列号、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、设备 ID、命令和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码命令令牌。边界至少覆盖空设备、空命令、ttl 为 0、重复执行、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
