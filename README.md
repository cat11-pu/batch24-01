# GSB Bugfix Task
## 题面
MFA 的 TOTP 校验现在只要格式像六位数字就放行，不校验时间步、不拦重放，同一个验证码能反复用。totp_guard.py 是核心，tests/test_totp_guard.py 15 个红。要修成只接受当前时间窗内的六位数字、拒绝过期和未来步长、同一验证码只能消费一次、空值和非法字符明确报错。修完 15 个测试后，还要保证 1000 组随机验证码没有重放，32 线程并发消费同一验证码只能成功一次；不许改测试或硬编码验证码。边界至少覆盖空串、长度错误、非数字、NUL、换行、重放、时间倒退。

## 运行方式
```bash
python -m pytest tests -q
```
