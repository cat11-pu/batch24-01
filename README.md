# GSB Bugfix Task
## 题面
合作伙伴沙箱密钥的沙箱密钥现在能猜、不绑合作伙伴、不过期、能重复用，撤销和轮换也不生效。sandbox_key.py 是核心，tests/test_sandbox_key.py 15 个红。要修成随机且不可预测的沙箱密钥、绑定合作伙伴、环境和 scope、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机密钥、合作伙伴 ID、scope 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码沙箱密钥。边界至少覆盖空伙伴、空环境、ttl 为 0、越权 scope、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
