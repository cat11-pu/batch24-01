# GSB Bugfix Task
## 题面
文档系统要上线一套权限判定：角色有继承链，授权按资源类型和动作发放，显式拒绝要盖过继承来的允许，资源还带租户、属主和软删除状态。authorize 在 access_matrix.py，现有十五个用例全部失败。policy 里 roles 是角色到父角色的映射，grants 和 denies 都是 role/action/resource 三元组；继承要传递，环要报错，未知角色、动作、资源类型也要报错。删除资源、跨租户访问、无角色用户一律拒绝；属主对自己的未删除文档可以读写，但显式 deny 仍然优先。改好后我会用 1200 组随机策略和资源、24 个线程并发判定；用例不许改，策略结构不能写死。

## 运行方式
```bash
python -m pytest tests -q
```
