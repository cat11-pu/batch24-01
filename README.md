# GSB Bugfix Task
## 题面
年龄验证令牌的验证令牌现在能猜、不绑用户、不过期、能重复用，撤销和轮换也不生效。age_token.py 是核心，tests/test_age_token.py 15 个红。要修成随机且不可预测的验证令牌、绑定用户、验证方式和有效期、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、用户 ID、验证方式和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码验证令牌。边界至少覆盖空用户、空方式、ttl 为 0、重复验证、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
