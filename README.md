# GSB Bugfix Task
## 题面
多租户邀请码现在这套邀请码能猜、不绑租户管理员、不过期、能重复用，撤销和轮换也不生效。tenant_invite.py 是核心，tests/test_tenant_invite.py 15 个红。要修成随机且不可预测的邀请码、绑定租户归属和最大使用次数、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机邀请码、租户 ID 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码邀请码。边界至少覆盖空租户、空邀请码、ttl 为 0、重复使用、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
