# GSB Bugfix Task
## 题面
运维收到磁盘告警，解压目录一夜之间被塞满，inode 也见了底——上传的压缩包没有做任何体积约束，典型的 zip bomb。校验入口 validate_archive 在 zip_bomb_guard.py 里，仓库附带的 15 条断言现在跑起来全是失败。希望校验同时盯住压缩比、解压后总量、条目数、单条目大小和符号链接数量，空包、负数、任何一项越界都要报错。除了这 15 条，我还会用脚本生成 1200 个随机包、16 路并发调用校验函数；阈值从调用方传入，不写在代码里，用例文件也别动。高压缩比、超大解压、条目爆炸、单条目超限、symlink 和负数都要有对应用例。

## 运行方式
```bash
python -m pytest tests -q
```
