# GSB Bugfix Task
## 题面
审批流一次性令牌现在这套审批令牌能猜、不绑审批人、不过期、能重复用，撤销和轮换也不生效。approval_token.py 是核心，tests/test_approval_token.py 15 个红。要修成随机且不可预测的审批令牌、绑定审批人和单据范围、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、单据 ID、审批人角色和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码审批令牌。边界至少覆盖空审批人、空令牌、ttl 为 0、越权审批、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
