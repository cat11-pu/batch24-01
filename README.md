# GSB Bugfix Task
## 题面
改邮箱接口只校验新地址格式，不要求重新验证身份，拿到会话的人可以直接把账号邮箱换掉再走找回流程。reauth_guard.py 的 change_email 守着这道口子，当前十五个用例全部失败。改邮箱前必须同时通过密码和 MFA，最近一次认证不超过 300 秒，新地址要合法且不能带空白、换行，用户标识不能为空，任何一项不满足都抛 ValueError。之后我会拿 950 组随机参数、20 路并发调用验证；测试保持原样，时间窗作为参数传入。

## 运行方式
```bash
python -m pytest tests -q
```
