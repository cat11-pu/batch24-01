# GSB Bugfix Task
## 题面
图片代理先解析域名再决定要不要抓，解析结果里的内网地址没人看，攻击者把域名解析到 127.0.0.1 或云元数据地址就能打内网。check_host 在 dns_rebind.py，仓库十五个用例目前全部失败。主机名必须是非空字符串且不能带空白、换行，resolver 返回的地址列表不能为空，出现回环、私有网段、链路本地、IPv6 唯一本地、0.0.0.0 或混合公网私网都拒绝，解析器抛错也要转成 ValueError。改完我用 1000 组随机域名和解析结果、20 个线程并发检查；断言不能改，允许地址集合由调用方给出。

## 运行方式
```bash
python -m pytest tests -q
```
