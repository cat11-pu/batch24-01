# GSB Bugfix Task
## 题面
订单确认页把 query string 直接转成字典，同名参数后出现的覆盖前面的，攻击者塞两个 amount 就能让下单金额和风控看到的不是同一个值。parse_query 在 hpp_guard.py，仓库里的用例总共十五个，现在逐个都挂。要求同名键无论编码与否、带不带方括号、出现几次都算冲突并报错，空键、分号分隔、BOM、NUL、CR/LF 和非法百分号编码也要拒绝，正常单值查询照常返回。十五个绿掉以后，我会用 1400 组随机查询串、18 路并发解析；测试保持原样，键名不能写死。

## 运行方式
```bash
python -m pytest tests -q
```
