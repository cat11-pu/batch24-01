# GSB Bugfix Task
## 题面
报表后台让运营自选表和列，表名、字段名被原样拼进 SQL，分号、注释符和 UNION 都能塞进去。sql_guard.py 的 build_query 需要拦下这些输入，仓库自带的用例眼下十五条全挂。规则是：表名和列名只能来自调用方给的标识符约束，出现空白、引号、分号、注释、逗号、星号、NUL 或非字符串就抛 ValueError；过滤值必须走参数绑定，不能进 SQL 文本。改完我会生成 1300 组随机标识符和值、30 路并发调用；测试文件保持原样，表名和列名也不许写死。空表名、空列、非法类型、注释注入和值里的引号都要覆盖。

## 运行方式
```bash
python -m pytest tests -q
```
