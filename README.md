# GSB Bugfix Task
## 题面
智能门锁临时钥匙的临时钥匙现在能猜、不绑住户、不过期、能重复用，撤销和轮换也不生效。lock_key.py 是核心，tests/test_lock_key.py 15 个红。要修成随机且不可预测的临时钥匙、绑定住户、门锁和有效时段、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机钥匙、住户 ID、门锁 ID 和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码临时钥匙。边界至少覆盖空住户、空门锁、ttl 为 0、跨门锁使用、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
