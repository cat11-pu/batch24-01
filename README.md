# GSB Bugfix Task
## 题面
病历导出令牌的导出令牌现在能猜、不绑医生、不过期、能重复用，撤销和轮换也不生效。medical_export.py 是核心，tests/test_medical_export.py 15 个红。要修成随机且不可预测的导出令牌、绑定患者、导出范围和有效期、按 TTL 过期并清理、一次校验后作废、撤销和轮换立即失效。15 个用例跑绿后，再用 1000 组随机令牌、患者 ID、医生和过期时间和 32 线程并发校验，确认没有重放和越权；不许改测试或硬编码导出令牌。边界至少覆盖空医生、空患者、ttl 为 0、超范围导出、撤销后重放。

## 运行方式
```bash
python -m pytest tests -q
```
