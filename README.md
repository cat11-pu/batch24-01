# GSB Bugfix Task
## 题面
会话只在登录时记时间，之后既不看过期也不看闲置，浏览器放一个月还能直接操作。check_session 在 idle_timeout.py，套件里十五条断言眼下全红。创建时间、最后活跃时间和当前时间必须是非负整数且顺序合理，闲置超过阈值或总时长超过绝对上限返回 False，时间倒流、未来时间、布尔、浮点、字符串、None 和非法阈值都抛 ValueError。改完我造 1000 组随机会话状态、18 个线程同时判定；用例保持原样，两个阈值由参数传入。
