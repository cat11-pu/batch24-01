# GSB Bugfix Task
## 题面
备份命令执行现在直接把命令名和参数拼进 shell，分号、管道、命令替换、重定向、路径穿越都能注入。command_guard.py 是核心，tests/test_command_guard.py 15 个红。要修成只允许白名单命令、参数只能是字母数字和有限符号、拒绝所有 shell 元字符和路径分隔符。修完 15 个测试后，还要保证 1000 组随机命令和参数没有注入，32 线程并发校验不串白名单；不许改测试或硬编码输入。边界至少覆盖分号、管道、&、$()、反引号、换行、重定向、路径穿越。

## 运行方式
```bash
python -m pytest tests -q
```
