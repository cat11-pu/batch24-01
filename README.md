# GSB Bugfix Task
## 题面
优惠券核销没有原子状态机，同一张券能被两个请求同时核销，过期券、跨用户券和超限券也照常放行。coupon_redeem.py 的 redeem 是核心，tests/test_coupon_redeem.py 15 个红。要修成未使用券只能成功核销一次、绑定用户和活动、过期和超限拒绝、并发只成功一个。15 个测试通过后，再用 1000 组随机状态和 32 线程并发核销，确认不能重复；不许改测试或硬编码券号。边界至少覆盖空券、空用户、未知券、过期、已用、跨用户、超限和并发。

## 运行方式
```bash
python -m pytest tests -q
```
