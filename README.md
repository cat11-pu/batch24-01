# GSB Bugfix Task
## 题面
备份恢复要先验完整性：备份要带校验和、加密标记、创建时间、大小和保留期，校验和不符、未加密、已过期、超大小上限都拒绝；申请人不能自己批准，恢复原因不能为空，目标实例必须在允许列表，两个恢复请求并发只能放行一个。backup_restore.py 的 plan 负责审批，十五条用例眼下全挂。backup 和 request 用字典，时间取整数；类型错误、越权和冲突都算失败。审批压测：1380 组备份请求、27 个线程并行跑；断言文件别改，大小上限由使用方定。

## 运行方式
```bash
python -m pytest tests -q
```
